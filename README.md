# Parts + Labels

A web app to catalog electronic and mechanical parts and create customizable labels.

## Planned features

- Parts catalog with technical specifications and datasheets
- Inventory quantities and storage locations
- Labels with component images, pinouts, and resistor color codes
- Print-ready layouts and PDF export

## Stack

Next.js, TypeScript, MongoDB, HTML/CSS, and SVG.

## Development

Install dependencies and start the development server:

    pnpm install
    pnpm dev

Open http://localhost:3000.
